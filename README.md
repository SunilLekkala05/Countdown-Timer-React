# Countdown Timer React

A simple countdown timer application built using **React.js**.

## Features

* Set hours, minutes, and seconds
* Start countdown
* Pause timer
* Resume timer
* Reset timer
* Input validation for minutes and seconds
* Alert when the timer is finished

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS

## Getting Started

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Navigate to the project

```bash
cd Countdown-Timer-React
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

The application will open at:

`http://localhost:3000`

## Project Structure

```text
src/
├── App.js
├── App.css
├── InputTimer.js
├── OutputTimer.js
└── index.js
```

## How It Works

Enter the required hours, minutes, and seconds and click **Start**. The timer counts down every second. You can **Pause**, **Resume**, or **Reset** the timer at any time.

Minutes and seconds must be between **0 and 59**.
